# Bagrry

> **The AI Notepad for Back-to-Back Meetings.**
> Capture raw shorthand notes during your calls. Bagrry listens without bots, enhancing your human notes into structured recaps with verified sentence citations.

---

## What is Bagrry?

Most AI meeting tools send an intrusive bot into your calls and dump a 10-page unformatted transcript that nobody reads.

**Bagrry** is built on a human-guided approach:
1. **Zero Meeting Bots**: Records directly at the OS audio driver layer (Windows WASAPI loopback + microphone) separating host mic from attendee audio. It works invisibly across Zoom, Google Meet, Microsoft Teams, Slack Huddles, and WhatsApp calls without ever joining as an attendee.
2. **Split-Screen AI Notepad**: You type rough bullet points and shorthand impressions on the left; Bagrry combines your raw human notes with the verbatim transcript to generate structured executive summaries, decisions, and action items on the right.
3. **Verbatim Sentence Citations (`cite s_001`)**: Every claim and action item generated by the AI includes an interactive citation tag linking directly back to the spoken sentence and timestamped audio.
4. **Open Loops Inbox**: Automatically categorizes commitments across all conversations into **Owed by Me** (what you promised to ship) vs **Owed to Me** (deliverables promised to you by others).
5. **Local Confidentiality & MCP**: All transcripts, notes, and attendee dossiers reside on your local machine in SQLite with WAL mode. An embedded **Model Context Protocol (MCP)** server on port `47821` allows external AI tools like Claude Desktop and Cursor to query your meeting context securely.

## Core Capabilities

### 1. Dual-Channel Native Audio Pipeline
* Captures both the host microphone and the system audio loopback simultaneously using Windows WASAPI (and macOS CoreAudio).
* Built-in Voice Activity Detection (VAD) and ring-buffering for crystal-clear dual-track transcription without meeting bot permissions.

### 2. The Split-Pane Human-in-the-Loop Editor
* **Raw Scratchpad**: Markdown canvas optimized for rapid keyboard input during active calls.
* **Enhanced Synthesis**: Post-meeting enhancement that fills in missing names, exact metrics, dates, and technical specs grounded in the transcript.

### 3. Interactive Sentence Citations
* Clicking or hovering any citation tag opens a citation popover showing:
  - The exact verbatim sentence spoken.
  - Speaker identification (*Me* vs *Attendee*).
  - An inline audio playback scrubber to verify context.

### 4. Open Loops Tracking & 1-Click Follow-Ups
* Tracks commitments across meetings so nothing falls through the cracks.
* Generates 1-click recap emails and Slack messages formatted in your personal voice.

### 5. Local Model Context Protocol (MCP) Server
* Embedded JSON-RPC 2.0 server running locally on `http://127.0.0.1:47821`.
* Endpoints:
  - `GET /v1/notes` — List recent meeting notes.
  - `POST /v1/notes/search` — SQLite FTS5 full-text keyword and semantic search.
  - `POST /mcp` — Standard Model Context Protocol endpoint for Claude Desktop, Cursor, and custom AI agents.

## Getting Started

### Prerequisites

* [Node.js](https://nodejs.org/) (v18+) or [Bun](https://bun.sh/) (v1.2+)
* [Rust](https://www.rust-lang.org/) (latest stable)
* Windows 10/11 (or macOS 13+)

---

### Running the Desktop Application

```bash
cd desktop/tauri

# Install frontend dependencies
npm install

# Run the desktop application in development mode
npm run tauri dev
```

> **API Key Setup**: Add your Groq API key in **Settings** for cloud transcription (`whisper-large-v3-turbo`) and LLM enhancement (`llama-3.3-70b-versatile`). Offline mode uses local heuristic enhancements and offline Whisper STT.

---

### Running the Marketing & Download Site

```bash
cd web

# Install dependencies
npm install

# Start development server
npm run dev
```

Visit `http://localhost:3000` to preview the landing page, download portal, pricing tiers, and integration documentation.

## Privacy & Security

* **100% On-Device Storage**: All recordings, transcripts, and notes are saved directly to local SQLite databases.
* **Zero Cloud Telemetry**: Bagrry never retains audio logs, sends data to third-party databases, or trains machine learning models on your private conversations.
